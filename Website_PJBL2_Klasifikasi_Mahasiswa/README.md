# Website PJBL-2: Klasifikasi Data Mahasiswa

## Menjalankan di Windows
1. Install Python 3.
2. Buka folder ini di Visual Studio Code.
3. Pilih Terminal > New Terminal.
4. Install Flask: `py -m pip install flask`
5. Jalankan: `py app.py`
6. Buka browser: http://127.0.0.1:5000

## Kriteria
A = kehadiran minimal 80%; B = nilai minimal 80; U = seluruh mahasiswa.
Dataset adalah data fiktif untuk simulasi. Sesuaikan dengan arahan dosen.
